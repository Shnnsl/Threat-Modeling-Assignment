# Threat Modeling Assignment

This repository contains a software security threat modeling assignment created with OWASP Threat Dragon. The project analyzes a sample web application with user login, message-of-the-day functionality, and comment submission features.

## Project Purpose

The goal of this project is to identify potential security threats, document system components, analyze trust boundaries, and recommend mitigations that improve the security of the application design.

## Tools Used

- OWASP Threat Dragon
- STRIDE Threat Modeling Methodology
- GitHub for version control and documentation

## Application Scope

The modeled application includes:

- User authentication
- Message-of-the-day display
- Comment submission
- Web server
- Application server
- Data storage components

## Security Areas Reviewed

- Spoofing
- Tampering
- Repudiation
- Information Disclosure
- Denial of Service
- Elevation of Privilege
